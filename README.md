# PHISHING AWARENESS GUIDE

## 1. Introduction

The Phishing Awareness Guide is a cybersecurity awareness project developed to educate students, employees and general internet users about phishing attacks and other common cybersecurity threats.

Phishing is a form of cybercrime in which attackers use fraudulent emails, messages and websites to trick individuals into revealing confidential information such as passwords, banking details and personal information.

This project aims to improve cybersecurity awareness and encourage responsible online behaviour.

## 2. Project Objectives

The main objectives of this project are:

- To explain what phishing attacks are.
- To identify common cybersecurity threats.
- To educate users on recognising suspicious emails and messages.
- To provide practical security measures for protecting personal information.
- To encourage users to report cybersecurity incidents.
- To promote safe internet usage.

## 3. Common Cybersecurity Threats

### 3.1 Phishing

Phishing involves sending fraudulent communications that appear to come from trusted organisations or individuals.

Attackers use these communications to trick victims into clicking malicious links or providing confidential information.

**Prevention measures:**
- Verify the sender's email address.
- Avoid clicking suspicious links.
- Never share passwords or verification codes.
- Report suspicious messages.

### 3.2 Malware

Malware refers to malicious software designed to damage computer systems, steal information or gain unauthorised access to devices.

Examples include viruses, ransomware and spyware.

**Prevention measures:**
- Install reputable antivirus software.
- Keep operating systems updated.
- Avoid downloading files from untrusted websites.
- Scan suspicious attachments before opening them.

### 3.3 Social Engineering

Social engineering involves manipulating individuals into revealing confidential information or performing actions that compromise security.

Attackers may pretend to be IT employees, managers or trusted service providers.

**Prevention measures:**
- Verify unusual requests before responding.
- Do not disclose confidential information.
- Be cautious of unexpected phone calls and messages.
- Follow organisational security policies.

## 4. Essential Cybersecurity Tips

1. Create strong and unique passwords.
2. Enable multi-factor authentication.
3. Avoid suspicious links and attachments.
4. Update software and applications regularly.
5. Avoid sharing personal information with unknown individuals.
6. Lock devices when they are not in use.
7. Back up important information regularly.
8. Report suspicious cybersecurity activities.

## 5. Incident Reporting

Users should report suspicious activities such as:

- Phishing emails.
- Unauthorised account access.
- Malware infections.
- Suspicious website activity.
- Lost or stolen devices.

**Reporting procedure:**

1. Identify and record the suspicious activity.
2. Avoid interacting with suspicious links or attachments.
3. Report the incident to the IT department or SOC.
4. Provide relevant information about the incident.
5. Follow the security team's instructions.

## 6. Important Security Warning

The IT department will NEVER ask for an individual's password, verification code or banking details.

Always verify unexpected requests before sharing information.

## 7. Target Audience

This project is intended for:

- Students.
- Employees.
- Organisations.
- General internet users.

## 8. Conclusion

Cybersecurity awareness plays an important role in protecting individuals and organisations against online threats.

By understanding common cyberattacks and following recommended security practices, users can reduce cybersecurity risks and contribute to a safer digital environment.
