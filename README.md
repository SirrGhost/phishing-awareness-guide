# Phishing Awareness Guide

## Introduction
This project is a cybersecurity awareness resource designed to educate users about phishing attacks and online security threats.

## Project Objectives
- Explain what phishing is.
- Identify common phishing techniques.
- Teach users how to recognise suspicious messages.
- Provide security practices to prevent phishing attacks.
- Explain how to report cybersecurity incidents.

## Common Phishing Indicators
- Suspicious email addresses.
- Unexpected attachments.
- Urgent requests for personal information.
- Suspicious website links.
- Messages requesting passwords or banking details.

## Recommended Security Practices
1. Never share your password or verification codes.
2. Verify the sender before opening links.
3. Enable multi-factor authentication.
4. Avoid downloading unknown attachments.
5. Report suspicious emails to the IT department.

## Target Audience
Students, employees and general internet users.

## Project Purpose
To promote safe internet usage and improve cybersecurity awareness.
